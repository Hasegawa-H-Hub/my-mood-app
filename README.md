## 概要
その日の気分とひとことメモを記録し、振り返ることができるWebアプリケーションです。

職業訓練のグループワークで制作しました。

## 主な機能

- 記録の新規登録・更新・削除
- 気分による絞り込み
- 日付による期間検索
- 日付順の並び替え

## 使用技術

- Java / Spring Boot
- Thymeleaf
- MyBatis
- PostgreSQL
- HTML / CSS / JavaScript

## 開発環境

ローカル環境での動作を想定しています。
